# 🚀 Personal Portfolio Website

A clean, modern, fully responsive personal portfolio website built with HTML5, CSS3, and JavaScript. Designed to showcase projects, skills, services, and provide an integrated contact method.

---

## 🌟 Live Demo

🔗 **Main Portfolio:** (https://gb376052-cpu.github.io/MY_PORTFOLIO/)

---

## 🛠️ Tech Stack & Technologies

- **Frontend:** HTML5, CSS3 (Flexbox & Grid), JavaScript (ES6+)
- **Integrations:** [EmailJS SDK](https://www.emailjs.com/) (Client-side email service)
- **Deployment:** GitHub Pages
- **Icons & Typography:** Google Fonts, Emoji Icons

---

## ✨ Features

- 📱 **Fully Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- 🌓 **Dark / Light Mode Toggle:** Supports instant theme switching with persistent local storage memory.
- ✉️ **Working Contact Form:** Direct email delivery to Gmail inbox using EmailJS (with input validation).
- 📜 **Smooth Scroll & Animations:** Scroll-reveal animations and dynamic navbar highlighting.
- 🍔 **Mobile Navigation Menu:** Touch-friendly hamburger drawer for small screens.
